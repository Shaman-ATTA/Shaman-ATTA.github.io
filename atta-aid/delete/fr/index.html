ATTA Aid — Supprimer vos données

Application : ATTA Aid (Android, package com.attacorp.aid) · Développeur : ATTA CORP (développeur Google Play « ATTA ») · Contact : gamerazrabplay@gmail.com · Dernière mise à jour : 16 novembre 2026

En bref

ATTA Aid n’a ni comptes ni serveurs. Tout ce que l’application enregistre reste uniquement sur votre téléphone : vous pouvez le supprimer vous-même à tout moment, sans nous le demander.

Comment supprimer vos données

  1. Uniquement l’historique des messages : dans l’application, ouvrez Chat → Paramètres de la messagerie → Effacer l’historique.
  2. Quitter un groupe (supprime le groupe et sa clé du téléphone) : Chat → Paramètres de la messagerie → Mon groupe → Quitter le groupe.
  3. Tout en une fois : Paramètres Android → Applications → ATTA Aid → Stockage → Effacer les données (sur certains téléphones « Vider le stockage » ou « Gérer l’espace »).
  4. Désinstallez ATTA Aid : toutes ses données sont alors aussi supprimées du téléphone.

Ce qui est supprimé

Les options 3 et 4 suppriment tout ce que l’application enregistre sur votre téléphone :

  • votre pseudo de chat, l’identifiant d’appareil aléatoire et vos clés de chiffrement du chat (ainsi que les clés publiques de vos interlocuteurs) ;
  • votre historique des messages ;
  • les groupes et les clés de groupe ;
  • les utilisateurs bloqués et les signalements ;
  • votre tranche d’âge et le code PIN parental ;
  • la liste du sac d’urgence et les paramètres.

Ce que nous conservons

  • Le développeur ne conserve rien. Nous n’avons pas de serveurs et l’application ne nous envoie aucune donnée.
  • Les messages déjà envoyés sont enregistrés sur les téléphones des personnes qui les ont reçus. Elles seules peuvent les supprimer sur leurs appareils.
  • La liste du sac et les paramètres peuvent figurer dans votre propre sauvegarde Android de votre compte Google (les données du chat, les clés, la tranche d’âge et le PIN sont exclus des sauvegardes). Cette sauvegarde suit les paramètres de votre compte Google ; vous pouvez la supprimer dans Google Drive / les paramètres de sauvegarde Android.
  • Si vous nous avez écrit par e-mail (par exemple un signalement ou un avis à gamerazrabplay@gmail.com), vous pouvez nous demander de supprimer cette correspondance. Nous le faisons sous 30 jours.
